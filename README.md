# CPSC4420-Assignment3-Q-learning

### Setup

- download frozenlake-qlearning.py
- adjust gamma, alpha, epsilon, etc. variables as needed
- run frozenlake-qlearning.py
- I used google colab for writing and running code, which allows for easy integration with matplotlib

### Contents
- eval-episode-0.mp4 is a recording of a successful run by a trained agent
- Assignment3Results.zip contains all of the reward vs episode plots recorded from testing different variable values.
- frozenlake-qlearning.py contains all of the code used to train and evaluate the q-learning agent
